# Roteiro sugerido para apresentação final

1. **Problema:** informações de eventos automotivos costumam ficar espalhadas entre redes sociais, cartazes e mensagens.
2. **Solução:** Expo Automotiva centraliza atrações, programação, localização, orientações e inscrições em um site responsivo.
3. **Tecnologias:** HTML, CSS, JavaScript, Bootstrap no frontend; Node.js e Express na API; MySQL para persistência.
4. **Demonstração do visitante:** página inicial, filtros de categorias, programação por dia, mapa, informações de acesso e formulário de inscrição.
5. **Demonstração técnica:** mostrar as tabelas do MySQL, a API `/api/veiculos`, o POST `/api/inscricoes` e o registro gravado no banco.
6. **Administração:** apresentar a área protegida por token e a consulta/alteração de status de inscrições.
7. **Responsividade:** demonstrar a mesma página em computador e celular.
8. **Publicação e testes:** informar a URL real somente após o deploy; apresentar o checklist preenchido com os testes efetivamente realizados.
9. **Próximos passos:** autenticação administrativa mais completa, formulário visual para cadastro/edição, envio de confirmação por e-mail, QR Code e integração de ingressos caso sejam solicitados.
